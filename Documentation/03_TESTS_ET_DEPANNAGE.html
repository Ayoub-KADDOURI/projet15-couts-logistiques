Si quelque chose bloque

SymptômeAction concrète
Macros bloquées / bouton inactifFermer le fichier ; vérifier provenance et Propriétés > Débloquer si disponible ; rouvrir le fichier du projet et autoriser son contenu. Sur un PC administré, demander l’autorisation au responsable. Ne pas baisser globalement la sécurité.
« L’exécution de scripts est désactivée » ou script interditLe lanceur respecte la politique du PC. Si une marque Internet est la cause, vérifier les Propriétés des PS1 transférés. Une politique Restricted ou AllSigned peut exiger l’intervention du responsable informatique ou un PC où ces scripts sont autorisés. Ne pas employer ExecutionPolicy Bypass.
Power BI introuvable dans Program FilesInstaller l’édition classique 64 bits depuis Microsoft ; vérifier le chemin donné dans le guide. La seule édition Store n’est pas détectée par cette version du lanceur.
Le script ne trouve pas le décisionnelOuvrir la copie située dans le même dossier que le script, fermer les menus pendant la configuration et fermer les autres copies de même nom. Garder les deux livres dans la même session Excel et le même compte Windows.
Ancien chemin Ayoub / source introuvableRecréer le PBIX à partir du PBIT avec le vrai DossierExports local, enregistrer au nom et à l’endroit exacts, fermer Power BI puis relancer la configuration Excel et enregistrer.
Deux fenêtres Power BI / enregistrement verrouilléTerminer les modifications nécessaires puis fermer les fenêtres du même rapport. Ne pas ouvrir à la fois le modèle et le rapport pour la démonstration. Relancer le bouton avec une seule copie.
Actualisation en cours trop longtempsGarder le bureau Windows déverrouillé. Regarder les éventuelles demandes de Power BI : premier accueil, confidentialité, erreur de source. Lire et résoudre le message ; consulter le journal pour l’étape exacte, puis relancer après la fin ou l’erreur.
Fichier export de la minute ouvert dans ExcelFermer cet export de résultats avant de relancer le bouton. Les XLSX datés sont des sorties de lecture, pas les applications à garder ouvertes.
Les totaux diffèrentVérifier janvier, effacer les filtres, comparer le même indicateur. Coût global et coût affecté aux commandes sont distincts. Lire le nom de la source et le journal ; ne pas masquer l’écart en modifiant une mesure ou les données.
Février/mars refusé ou aucune période importéeUtiliser janvier clôturé pour cette livraison. Ne pas forcer la clôture ; les mois suivants nécessitent le travail de validation métier et un nouvel import/export.
n.d. sur un indicateur ou comparaison fournisseur partielleConsulter les limites du guide 04 : données manquantes et limites du moteur livré. Ne pas remplacer n.d. par zéro.

Remettre la démonstration dans son état initial

Les clics de démonstration peuvent produire des exports, des traces et des mises à jour d’état. Pour repartir strictement de la livraison, fermer les applications après avoir traité les modifications à conserver, puis extraire le ZIP dans un nouveau dossier. Ne pas écraser un classeur ouvert. Refaire les étapes PBIT et configuration dans ce nouveau dossier. Le code VBA livré reste celui de Tarik.

Si Power BI est indisponible le jour même, utiliser Documentation\Apercu_Rapport_PowerBI.pdf comme aperçu statique. Il ne démontre pas une actualisation sur ce PC. Les anciens journaux contenus dans Preuves_PC_Ayoub prouvent seulement les essais effectués chez Ayoub.
