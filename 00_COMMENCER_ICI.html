Préparer le PC de démonstration

Transférer le dossier entier. Il contient les deux applications finales, le rapport Power BI, son modèle de configuration, les exports initiaux et tous les guides. Les copies Excel sont identiques aux fichiers reçus ; les chemins seront adaptés sur le PC de votre camarade.

L’ordre à suivre

  1. Extraire le ZIP dans un dossier local modifiable, par exemple Documents\Projet15_Demo. Garder tous les fichiers ensemble. Ne pas travailler directement dans le ZIP ou sur une clé USB.
  2. Ouvrir 01_INSTALLATION.html et installer les prérequis : Windows 64 bits, Excel de bureau avec VBA et Power BI Desktop 64 bits. Le lanceur fourni attend l’installation classique de Power BI dans C:\Program Files\Microsoft Power BI Desktop\bin.
  3. Lancer 1_VERIFIER_PC.cmd, puis ouvrir les deux classeurs Excel du dossier et autoriser leur contenu seulement après vérification de leur provenance. Fermer les menus des applications pour revenir aux feuilles de lancement pendant la configuration.
  4. Créer le rapport pour ce PC : ouvrir Projet15_Modele_Auto.pbit, renseigner DossierExports avec le chemin complet du sous-dossier Exports, puis enregistrer sous Projet15_Rapport_Auto.pbix à la racine du dossier, en remplaçant la copie fournie. Fermer Power BI après cet enregistrement.
  5. Lancer 2_CONFIGURER_CONNEXIONS.cmd. Revenir dans Excel et enregistrer le décisionnel avec Ctrl+S. Cette étape règle les trois chemins et crée le raccourci local appelé par le bouton.
  6. Rouvrir le menu du décisionnel et cliquer sur « Ouvrir le rapport Power BI ». Attendre la fin : le bouton exporte les résultats, actualise Power BI, vérifie les chiffres et enregistre le PBIX. Le pied de page indique le fichier réellement chargé.
